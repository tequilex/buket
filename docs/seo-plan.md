## Главный методологический урок

**Вордстат — это Яндекс. Google Search Console — это Google.** Я три сессии строил
стратегию на Вордстате с привязкой к Краснодару и переносил выводы на весь сайт.
Когда появились данные GSC, три вывода оказались неверными — см. «Опровергнутые
гипотезы».

Правило на будущее: **Вордстат годится для оценки спроса, GSC и Вебмастер — для
решений.** Первый показывает, что люди ищут в принципе; вторые — что происходит
с конкретным сайтом. Решения принимаются по вторым.

## Что дальше

Данные GSC задают приоритет: **не вширь, а вглубь.** При позиции 20,3 задача не
найти новые запросы, а подняться по тем, где уже показывают.

Три страницы дают больше половины показов — с них и начинать:

1. `/catalog/myasnye/` — 1 012 показов
2. `/catalog/sladkie/` — 832
3. `/locations/krasnodar/` — 740

Плюс фруктовые, которые в сумме дают больше 900 и которые я ошибочно списал.

Новые страницы (получатели, учителя, дети, блог) — только после того, как
существующие поднимутся. Иначе повторится история с «коллегой»: страница с
четырьмя запросами в месяц, наполненная текстом впустую.

### Сезонность (Вордстат, Краснодар)

Остаётся верной для Яндекса. Два разных сезона:
- **февраль** — мужские и съедобные букеты (пик 779 и 586)
- **август–сентябрь** — сладкие (пик 352 в сентябре, февраль только 237)
- март — провал по всем головам, 8 марта в нише не работает

«Букет на 23 февраля»: декабрь 7, **январь 60, февраль 617**, март 21. Спрос
стартует в январе — значит страница должна быть в индексе к концу декабря.

## Справочник

### Яндекс Вебмастер (сверено со справкой 2026-10-05)
- **Файлы Sitemap.** Робот загрузит «в течение двух недель». Ускоренное
  обновление — **10 раз за 30 дней**.
- **Переобход страниц.** Лимит обновляется ежедневно. Обработка «до трёх дней».
- **Региональность.** Путь через Вебмастер закрыт: требует полный адрес текстом.
  Остаётся Яндекс Бизнес.
- **Малоценные страницы.** Яндекс перепроверяет их сам, «почти каждый день», и
  ждёт изменившегося контента, а не повторной заявки.

### Yandex Wordstat MCP
Цены за **1000** вызовов: `top_requests` и `dynamics` — 20 ₽, `regions` — 50 ₽,
`list_regions` бесплатно. Лимит 100 вызовов в час.

**Ловушка:** `top_requests` и `regions` считают только последние 30 дней.
Сезонную фразу вне сезона они вернут пустой. Для сезонности — только `dynamics`,
`toDate` должен быть последним днём месяца.

ID регионов: Краснодар **35**, край 10995, Адыгея 11004, Майкоп 1093.

### Хостинг
Timeweb App Platform, статический экспорт. Конфиг сервера недоступен.
Несуществующие адреса отдают **главную с кодом 200** — SPA-фолбэк, выключить
нельзя. Спасает canonical: он указывает на главную, и поисковики склеивают.

Сборка обязана идти с `NEXT_PUBLIC_SITE_URL=https://gastro-buket.ru`.

### Быстрая проверка прода

```sh
curl -sL https://gastro-buket.ru/sitemap.xml | grep -o '<loc>[^<]*</loc>' | sed 's/<[^>]*>//g' \
  | while read u; do printf '%s %s\n' "$(curl -s -o /dev/null -w '%{http_code}' "$u")" "$u"; done

curl -sL https://gastro-buket.ru/ | python3 -c "
import re,sys,json
for m in re.findall(r'type=\"application/ld\+json\"[^>]*>(.*?)</script>',sys.stdin.read(),re.S):
    print(json.loads(m)['@type'])"
```
